# Air Pollution Prediction System

A Machine Learning-based web application that predicts air quality using environmental parameters.

## Features

- Machine Learning using Random Forest Classifier
- Flask Backend
- HTML, CSS, Bootstrap Frontend
- JavaScript Fetch API
- Air Quality Prediction
- Confidence Score
- Health Recommendations

## Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Bootstrap
- JavaScript

## Installation

```bash
git clone <repository-url>
cd AirPollutionPrediction

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt

python app.py
```

Open:

```
http://127.0.0.1:5000
```

## Model

Random Forest Classifier

Accuracy: **95.9%**
